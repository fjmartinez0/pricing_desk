X adds Grok Imagine Video 1.5 Lite to API from $0.02/sec, up to 1080p
Verified Oct 12, 2026·AI & Machine Learning·Direction: up
The changegrok-imagine-video plan — new plan.
1 change·2 captures·Oct 5, 2026 → Oct 12, 2026
What happened
Between the Oct 5, 2026 and Oct 12, 2026 captures of X's pricing page, Pulse recorded one change: New model grok-imagine-video-1.5-lite (Text, Image to Video) added to API pricing: $0.01 per input image, from $0.02 per second, 480p/720p/1080p. Pulse files it as a packaging change (new plan) with an upward direction. The current page lists grok-4.3 at $1.25 per 1M input tokens + $2.5 per 1M output tokens, grok-build-0.1 at $1 per 1M input tokens + $2 per 1M output tokens, grok-imagine-image-quality at $0.01 per input image + $0.05 per output image (1K resolution), grok-imagine-image at $0 per input image + $0.02 per output image (1K resolution) and grok-imagine-video at $0.01 per input second of video + $0 per input image.
It lands 49 days after X's previous change, "X drops grok-4.5, adds Imagine image/video models and free Playground perk" (Aug 24, 2026). Before that Pulse recorded "x.ai: Speech-to-Speech Voice API pricing changed from flat rate to starting-at" (Aug 5, 2026). X has been tracked since 2025-10-11.
In the same window You.com, fal, Voxel51, Upstage and Together AI also changed their AI & Machine Learning pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
