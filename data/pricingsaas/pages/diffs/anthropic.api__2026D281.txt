What happened
Between the Oct 5, 2026 and Oct 8, 2026 captures of Anthropic's pricing page, Pulse recorded 2 changes: Haiku 5.5 added to Latest models: input $0.10 / output $0.50 per MTok (prompts >100K: $0.50 / $2.50), cache read $0.01 / write $0.125 (>100K: $0.05 / $0.625). Haiku 4.5 moved to Legacy models with prices unchanged ($1/$5, cache $0.10/$1.25); Sonnet 5.5 prompt caching read price cut from $0.20 to $0.10 per MTok; cache write ($2.50), input ($2) and output ($10) unchanged. Pulse files it as a pricing change (price decrease, new plan) with a downward direction. Pulse's latest capture (Oct 12, 2026) lists Haiku 4.5 at $5 per MTok output + $1.25 per MTok cache write, Sonnet 5 at $2 per MTok input + $10 per MTok output, Opus 5 at $6.25 per MTok cache write + $0.5 per MTok cache read, Fable 5 at $12.5 per MTok cache write + $1 per MTok cache read and Opus 4.8 at $6.25 per MTok cache write + $5 per MTok input.
It lands 11 days after Anthropic's previous change, "Anthropic API: Opus 5.5 launches, replaces Opus 5 as flagship" (Sep 28, 2026). Anthropic has been tracked since 2024-11-17.
