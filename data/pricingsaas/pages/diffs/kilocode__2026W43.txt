What happened
Between the Oct 12, 2026 and Oct 19, 2026 captures of Kilo Code's pricing page, Pulse recorded one change: Free plan now includes commercial use rights for 40K+ Anaconda Core packages. Pulse files it as a product change (feature added) with an upward direction. The current page lists Teams at $15, Kilo Pass Starter at $19, Kilo Pass Pro at $49, Kilo Pass Expert at $199 and Cloud Compute at $1.2 per hour — Cloud Agent (Standard) + $0.6 per hour — Cloud Agent (Docker).
It lands 7 days after Kilo Code's previous change, "Kilo Code rebrands Teams Shared agent modes as Shared custom agents" (Oct 12, 2026). Before that Pulse recorded "Kilo Code: Teams trial redefined as Enterprise trial" (Aug 31, 2026) and "Kilo Code: New Cloud Compute usage pricing + 5% credit purchase fee" (Aug 4, 2026). Kilo Code has been tracked since 2026-07-15.
In the same window Cursor, GitHub, Replit, Windsurf and JetBrains also changed their Software Development & Testing pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
