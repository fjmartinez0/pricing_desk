What happened
Between the Aug 24, 2026 and Aug 31, 2026 captures of OpenAI's pricing page, Pulse recorded one change: Business split into Standard seat ($20/mo annual, $25/mo monthly, unchanged) and new Premium seat ($100/mo annual, $125/mo monthly, 5x usage, no 5-hour limit); Business now capped at 200 employees (previously unbounded). In detail: Business plan restructured from single per-user pricing into two seat types: Standard seat ($20/mo annual, $25/mo monthly - unchanged) and new Premium seat ($100/mo annual, $125/mo monthly) offering 5x usage with no 5-hour limit. Business is now also capped at 200 employees (previously unbounded). Pulse files it as a packaging change (package change) with a neutral direction. Pulse's latest capture (Oct 5, 2026) lists gpt-image-2.5-flare at $2 per 1M cached image input tokens + $30 per 1M image output tokens, gpt-6.1-sol at $0.2 per 1M cached input tokens (long context) + $2 per 1M input tokens (short context), gpt-6-luna at $0.25 per 1M cache write tokens (long context) + $0.2 per 1M input tokens (long context), gpt-5.6-sol at $30 per 1M output tokens (long context) + $8 per 1M input tokens (long context) and gpt-6-astra at $20 per 1M input tokens (long context) + $1 per 1M cached input tokens (short context).
It lands 112 days after OpenAI's previous change, "Openai API raises GPT-Realtime-2 text output 50%, adds translate" (May 11, 2026). Before that Pulse recorded "Openai API cuts image output pricing, launches GPT-image-2" (Apr 27, 2026), "Openai API slashes web search tool price 60% to $10 per 1k calls" (Apr 2, 2026) and "Openai API triples GPT-5 mini pricing, launches budget nano tier" (Mar 24, 2026). OpenAI has been tracked since 2023-11-14.
