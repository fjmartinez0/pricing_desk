What happened
Between the Oct 19, 2026 and Oct 26, 2026 captures of You.com's pricing page, Pulse recorded one change: New Inference Router API endpoint added to the API lineup: run leading open-weight AI models through one API; price varies by model. Pulse files it as a product change (feature added) with an upward direction. Pulse's latest capture (Oct 27, 2026) lists Search API at $5 per 1k calls, Contents API at $1 per 1k pages, Answer API at $5 per 1k calls, Research API Lite at $12 per 1k calls and Research API Standard at $50 per 1k calls.
It lands 83 days after You.com's previous change, "You.com: Web Search API now freemium (free 100/day + $5/1k after)" (Aug 4, 2026). You.com has been tracked since 2026-04-28.
In the same window OpenAI, Google and Gemini also changed their AI & Machine Learning pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
