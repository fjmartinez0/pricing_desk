What happened
Between the Aug 17, 2026 and Aug 24, 2026 captures of DeepSeek's pricing page, Pulse recorded 2 changes: Peak-hours footnote now specifies peak pricing applies Monday through Friday only, so weekends are always billed at off-peak rates; previously the schedule applied every day; New deepseek-v4-flash-vision-exp model added to the pricing table, priced identically to deepseek-v4-flash ($0.22 off-peak / $0.44 peak per 1M cache-miss input tokens, $0.66 off-peak / $1.32 peak per 1M output tokens, 2500 c. In detail: New deepseek-v4-flash-vision-exp model added to the pricing table, priced identically to deepseek-v4-flash ($0.22 off-peak / $0.44 peak per 1M cache-miss input tokens, $0.66 off-peak / $1.32 peak per 1M output tokens, 2500 concurrency); a new footnote states images are converted to tokens by dimension and billed as input tokens, and FIM Completion is not supported. Pulse files it as a pricing change (discount change, new plan) with an upward direction. Pulse's latest capture (Oct 19, 2026) lists DeepSeek Flash at $0.15 per 1M input tokens (cache miss) + $0.3 per 100M input tokens (cache hit) and DeepSeek V4 Pro at $0.66 per 1M input tokens (cache miss) + $2.2 per 100M input tokens (cache hit).
It lands 7 days after DeepSeek's previous change, "DeepSeek: API pricing restructured to peak/off-peak billing, prices roughly double" (Aug 17, 2026). Before that Pulse recorded "DeepSeek: dropped peak/off-peak pricing plan, warns of broader increase" (Aug 11, 2026) and "DeepSeek: announced peak/off-peak surge pricing (2x during peak hours)" (Aug 3, 2026). DeepSeek has been tracked since 2026-05-16.
