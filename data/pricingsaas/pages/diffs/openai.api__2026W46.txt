What happened
Between the Nov 2, 2026 and Nov 9, 2026 captures of OpenAI's pricing page, Pulse recorded one change: GPT-5.6 Sol's promotional pricing window was extended: previously open-ended 'at least through November 21, 2026', now set to a firm end date of November 30, 2026. Pulse files it as a pricing change (discount change) with a neutral direction. The current page lists gpt-image-2.5-flare at $2 per 1M cached image input tokens + $30 per 1M image output tokens, gpt-6.1-sol at $0.20 per 1M cached input tokens (long context) + $2 per 1M input tokens (short context), gpt-6-luna at $0.25 per 1M cache write tokens (long context) + $0.20 per 1M input tokens (long context), gpt-5.6-sol at $30 per 1M output tokens (long context) + $8 per 1M input tokens (long context) and gpt-6-astra at $20 per 1M input tokens (long context) + $1 per 1M cached input tokens (short context).
It lands 35 days after OpenAI's previous change, "Openai API halves GPT-6.1 Sol cached input price to $0.10 per 1M tokens" (Oct 5, 2026). Before that Pulse recorded "Openai API Business: new $100/mo Premium seat tier + 200-employee cap" (Aug 31, 2026). OpenAI has been tracked since 2023-11-14.
In the same window X, Metabase, Anthropic, Microsoft and Google also changed their AI & Machine Learning pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
