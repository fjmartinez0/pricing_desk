What happened
Between the Oct 5, 2026 and Oct 12, 2026 captures of Anthropic's pricing page, Pulse recorded one change: Haiku 5.5 replaces Haiku 4.5 at lower rates ($0.10/$0.50 per MTok in/out, tiered at 100K prompts); Haiku 4.5 moved to Legacy. Sonnet 5.5 cache read $0.20 to $0.10 per MTok. Pulse files it as a pricing change (price decrease) with a downward direction. The current page lists Haiku 4.5 at $5 per MTok output + $1.25 per MTok cache write, Sonnet 5 at $2 per MTok input + $10 per MTok output, Opus 5 at $6.25 per MTok cache write + $0.5 per MTok cache read, Fable 5 at $12.5 per MTok cache write + $1 per MTok cache read and Opus 4.8 at $6.25 per MTok cache write + $5 per MTok input.
It lands 3 days after Anthropic's previous change, "Anthropic API launches Haiku 5.5 at $0.10/$0.50, halves Sonnet 5.5 cache reads" (Oct 8, 2026). Before that Pulse recorded "Anthropic API: Opus 5.5 launches, replaces Opus 5 as flagship" (Sep 28, 2026). Anthropic has been tracked since 2024-11-17.
In the same window Google, X, Mistral AI, Microsoft and OpenAI also changed their AI & Machine Learning pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
