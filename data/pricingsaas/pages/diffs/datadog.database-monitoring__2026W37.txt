What happened
Between the Aug 31, 2026 and Sep 7, 2026 captures of Datadog's pricing page, Pulse recorded one change: FAQ renamed 'database host' to 'billable host', redefining it as a database instance (self-hosted or cloud-managed) running one or more logical databases, not just any monitored physical/virtual server. Pulse files it as a packaging change (metric change) with a neutral direction. The current page lists Database Monitoring at $70.
It lands 49 days after Datadog's previous change, "Datadog Database Monitoring Database Monitoring: AI-powered root cause analysis agent removed from Features" (Jul 20, 2026). Before that Pulse recorded "Datadog Database Monitoring DBM: added AI root-cause agent, auto-optimization, ClickHouse/Supabase" (Jul 2, 2026). Datadog has been tracked since 2023-11-14.
In the same window Grafana, Sumologic, Splunk, Dynatrace and New Relic also changed their Cloud & DevOps pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
