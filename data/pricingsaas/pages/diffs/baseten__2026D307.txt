What happened
Between the Nov 2, 2026 and Nov 3, 2026 captures of Baseten's pricing page, Pulse recorded 2 changes: Basic/Pro/Enterprise plan cards replaced by Pay as you go and Production scale tiers; new Sandboxes usage pricing added (CPU $0.0655/hr, RAM $0.0211/GB-hr, snapshots $0.20/GB-mo); joey-1 model ($0.01 input) removed from Model APIs token pricing table. Pulse files it as a packaging change (add-on removed, package change) with a downward direction. The current page lists Pro at $1, Enterprise at $1 and Basic at $1.32 DeepSeek V4 Pro 0813 input (per 1M tokens) + $0.30 Kimi K3 cache input (per 1M tokens).
It lands one day after Baseten's previous change, "Baseten reveals elephant-1 & mammoth-1 pricing, adds joey-1 ($0.01/1M)" (Nov 2, 2026). Before that Pulse recorded "Baseten adds Base Labs joey-1 model to Model API rate table at $0.01 input" (Oct 30, 2026), "Baseten: Input pricing revealed for elephant-1 ($0.035) & mammoth-1 ($0.10)" (Oct 29, 2026) and "Baseten: Model APIs: Reflection Beam token prices cut: input $1.30 to $0.40, cache input $0.13 to $0.04, output $4.30…" (Oct 26, 2026).
