What happened
Between the Oct 5, 2026 and Oct 12, 2026 captures of AgileHero's pricing page, Pulse recorded 2 changes: Pro card and comparison table add REST API and webhooks: public REST API (OAuth), outbound webhooks (Free 2 endpoints, Pro 20), API rate limit 150 vs 600 req/min; Retrospective boards upgraded to guided retrospectives with 16 templates, blind voting and actions list; team health checks added (Pro only). In detail: Free card and comparison table add REST API and webhooks for all plans: public REST API (OAuth) on Free and Pro, outbound webhooks (Free 2 endpoints, Pro 20), API rate limit 150 vs 600 req/min. Pulse files it as a product change (feature added) with an upward direction. The current page lists Pro at $10.
