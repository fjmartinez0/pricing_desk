What happened
Between the Sep 21, 2026 and Sep 28, 2026 captures of Cube's pricing page, Pulse recorded one change: Free plan feature list now includes an MCP server for AI agents, alongside existing semantic model and workbooks/dashboards agents and analytics chat. Pulse files it as a product change (feature added) with an upward direction. The current page lists Premium at $20 and Starter at $40.
It lands 28 days after Cube's previous change, "Cube quietly drops DAX API for Power BI from Enterprise plan lineup" (Aug 31, 2026). Before that Pulse recorded "Cube adds dbt integration to Compare Features table across all plans" (Jul 20, 2026). Cube has been tracked since 2026-04-29.
