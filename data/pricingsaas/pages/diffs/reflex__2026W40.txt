What happened
Between the Sep 21, 2026 and Sep 28, 2026 captures of Reflex's pricing page, Pulse recorded 3 changes: Free plan copy/features rewritten (publish app, database, auth) from framework-first messaging; Pro usage tiers now show explicit $25/$50/$100/$200 replacing 5x/10x/20x/40x multiplier badges; Enterprise cloud narrowed from AWS/GCP/Azure/Databricks to Google Cloud only; repo sync narrowed to GitHub only; added managed database, public sign-in, always-on deploys, no session limits, access restricti. In detail: Enterprise cloud narrowed from AWS/GCP/Azure/Databricks to Google Cloud only; repo sync narrowed to GitHub only; added managed database, public sign-in, always-on deploys, no session limits, access restriction; Pro plan hosted-app limit changed from a fixed cap of 10 apps to open-ended 'Multiple' in the comparison table; Pro card now says 'Publish multiple apps' instead of a specific app count. Pulse files it as a packaging change (package change, feature change, limit increase) with an upward direction. Pulse's latest capture (Oct 19, 2026) lists Pro at $25.
It lands 7 days after Reflex's previous change, "Reflex moves App Code Download to Free plan, reframes Enterprise pitch" (Sep 21, 2026). Before that Pulse recorded "Reflex guts Pro plan: flat $200/mo replaced by $25 base + usage tiers" (Aug 24, 2026) and "Reflex: Pro plan promo price ($3/mo) expired, reverted to $200/mo" (Aug 10, 2026). Reflex has been tracked since 2026-07-05.
