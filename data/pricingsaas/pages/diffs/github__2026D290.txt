What happened
Between the Oct 16, 2026 and Oct 17, 2026 captures of GitHub's pricing page, Pulse recorded one change: Secret scanning: 'Copilot secret scanning' renamed 'AI detection for alerts' (existing code), and new 'AI detection for push protection' (blocks pushes with secrets) added; both marked usage-based. In detail: Secret Protection: new 'AI detection for push protection' feature added (uses AI to detect unstructured secrets like passwords and block pushes containing them), priced usage-based on paid plans; existing 'Copilot secret scanning' renamed 'AI detection for alerts' (still included). Pulse files it as a product change (feature added) with an upward direction. Pulse's latest capture (Oct 19, 2026) lists Team at $4, Enterprise at $21, GitHub Codespaces at $0.18 per core hour compute + $0.07 per GB storage and Git Large File Storage at $5.
It lands 131 days after GitHub's previous change, "GitHub adds cloud sandbox for Copilot agent workflows" (Jun 8, 2026). Before that Pulse recorded "GitHub Copilot free tier loses 50 monthly chat requests" (Jun 1, 2026), "GitHub Shifts Copilot to Usage-Based Billing Model" (May 4, 2026) and "GitHub Renames Protected Branches to Repository Rules with Expanded Scope and Corrects Git LFS Pricing to $5/month for 50 GB" (Q3 2025). GitHub has been tracked since 2023-11-14.
