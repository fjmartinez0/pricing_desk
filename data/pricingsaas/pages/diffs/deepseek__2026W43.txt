What happened
Between the Oct 12, 2026 and Oct 19, 2026 captures of DeepSeek's pricing page, Pulse recorded 2 changes: New standalone Search and Fetch APIs priced at $0.75 per 1,000 successful requests each; currently free via Harness/Claude Code/Codex, per-request billing starts Nov 1, 2026; Flash model version updated from DeepSeek-V4.1-Flash to DeepSeek-V4.1-Flash-1017; token prices unchanged. Pulse files it as a packaging change (new add-on, feature change) with an upward direction. The current page lists DeepSeek Flash at $0.15 per 1M input tokens (cache miss) + $0.3 per 100M input tokens (cache hit) and DeepSeek V4 Pro at $0.66 per 1M input tokens (cache miss) + $2.2 per 100M input tokens (cache hit).
It lands 2 days after DeepSeek's previous change, "DeepSeek launches Search and Fetch APIs at $0.75 per 1,000 requests" (Oct 17, 2026). Before that Pulse recorded "DeepSeek: peak-hour billing now excludes Chinese public holidays" (Sep 21, 2026), "DeepSeek extends 50% off-peak API discount to Chinese public holidays all day" (Sep 20, 2026) and "DeepSeek merges v4-flash and vision-exp into cheaper Flash V4.1" (Sep 14, 2026). DeepSeek has been tracked since 2026-05-16.
