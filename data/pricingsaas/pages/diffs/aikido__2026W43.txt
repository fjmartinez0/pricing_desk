What happened
Between the Oct 12, 2026 and Oct 19, 2026 captures of Aikido Security's pricing page, Pulse recorded one change: SIEM Integration added to the Advanced plan feature list (Priority Support bullet now followed by SIEM Integration). Pulse files it as a product change (feature added) with an upward direction. The current page lists Basic at $315, Pro at $630, Advanced at $945 and Typical Pentest at $4,000 assessments.
It lands 7 days after Aikido Security's previous change, "Aikido Security launches Max add-on with unlimited AI credits, FedRAMP now Enterprise" (Oct 12, 2026). Before that Pulse recorded "Aikido Security adds Code Coverage to paid plan, above PR Code Quality Checks" (Oct 5, 2026), "Aikido Security: Container image scan limit doubled across paid tiers" (Aug 17, 2026) and "Aikido Security: Code Quality feature scoped down to PR-level checks" (Aug 10, 2026). Aikido Security has been tracked since 2026-06-26.
