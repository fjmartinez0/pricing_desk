What happened
Between the Oct 19, 2026 and Oct 26, 2026 captures of Workable's pricing page, Pulse recorded 2 changes: Trial copy changed: '15-day trial includes the complete feature set of the Standard plan' now 'Complete feature set of the Enterprise plan'; 15-day length no longer stated; Workable Agent add-on card (3,000 free AI credits) replaced by Job Brief Agent included on ATS plans; Sourcing, Screening, Engagement agents listed as add-ons using AI credits; 3,000 credits per ATS plan. In detail: Trial copy changed: '15-day trial includes the complete feature set of the Standard plan' now 'Complete feature set of the Enterprise plan' — trial now grants Enterprise features (15-day length still stated lower on page). Pulse files it as a packaging change (add-on change, trial change) with a neutral direction. Pulse's latest capture (Oct 27, 2026) lists Standard at $299, Premier at $599, Enterprise at $719, Texting at $89 and Performance & Engagement at $39.
It lands 63 days after Workable's previous change, "Workable: native language options increased 5→9 (Standard/Premier/Enterprise)" (Aug 24, 2026). Workable has been tracked since 2024-10-01.
