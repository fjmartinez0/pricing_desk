What happened
Between the Oct 19, 2026 and Oct 26, 2026 captures of MuchSkills's pricing page, Pulse recorded 2 changes: Starter plan now includes API and SCIM; the comparison table marks API access and SCIM as included on every plan (before: API not on Starter, SCIM Enterprise-only). The API bullet moved from the Professional card to Starter, which Professional inherits. Starter setup changed from self-serve to set up with our team; Skills database marketing claim reworded from 70,000+ capabilities to 20,000 indus. In detail: Skills database marketing claim reworded from 70,000+ capabilities to 20,000 industry-specific skills (12,000+ tech skills and 9,700+ certifications unchanged); different metric, not a plan limit. Pulse files it as a product change (feature added, positioning) with an upward direction.
It lands 21 days after MuchSkills's previous change, "MuchSkills: Starter price hidden behind sales CTA, Compliance plan added" (Oct 5, 2026). MuchSkills has been tracked since 2026-03-01.
In the same window Thinkific, Podia, Udemy and Kajabi also changed their Workforce Management pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
