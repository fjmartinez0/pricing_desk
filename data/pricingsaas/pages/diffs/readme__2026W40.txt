What happened
Between the Sep 21, 2026 and Sep 28, 2026 captures of Readme's pricing page, Pulse recorded one change: Rebase & Resolve Conflicts added to Writing tools (Pro/Enterprise); MCP Metrics added to AI tools (all plans); Theme editor renamed/relaunched as Themes (all plans), all marked NEW. In detail: Added Rebase & Resolve Conflicts (Writing) and MCP Metrics (AI) as new features in the plan comparison grid; renamed 'Theme editor' to 'Themes' in the Design section (both marked NEW). Pulse files it as a product change (feature added) with an upward direction. The current page lists Pro at $250, Ask AI at $150 and Extended History & Logs at $100.
It lands 21 days after Readme's previous change, "ReadMe: Multiplayer editing (Pro) + Aggregated doc metrics (Enterprise) added" (Sep 7, 2026). Before that Pulse recorded "Readme hides Enterprise pricing, swaps CTA to 'Book a Demo'" (Aug 17, 2026) and "Readme cuts to 3 tiers, slashes admin seats, adds $20/mo per-admin fee" (Jul 4, 2026). Readme has been tracked since 2024-10-07.
