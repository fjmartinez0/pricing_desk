What happened
Between the Sep 21, 2026 and Sep 28, 2026 captures of Mapbox's pricing page, Pulse recorded one change: Mapbox added 'Introductory preview pricing' for Search Box API alongside unchanged Standard pricing. Sessions: first 500 free (vs 2,500 Standard), then $3.00/$2.75/$2.50 per 1,000 (vs $11.50/$10.00/$8.40/$6.60). Requests: first 50,000 free (vs 25,000 Standard), then $1.00/$0.85/$0.70 per 1,000 (vs $1.70/$1.50/$1.25). Calculator now defaults to the preview tiers. Pulse files it as a packaging change (package change) with a neutral direction. The current page lists Tileset Processing at $0.01 Monthly Active User, Tileset Hosting at $0.01 Monthly Active User, Japan Weather Layers at $0.25 Monthly Active User, Vector Tiles API at $0.25 Monthly Active User and Raster Tiles API at $0.25 Monthly Active User.
It lands 97 days after Mapbox's previous change, "Mapbox simplifies pricing, drops legacy km2 tileset tiers" (Jun 22, 2026). Before that Pulse recorded "Mapbox expands web map load tiers to 5M with new volume pricing" (May 12, 2026), "Mapbox Launches Indoor Map Tiles API With Free Airport Floor Plans" (Apr 27, 2026) and "Mapbox Introduces Japan Weather Layers with 99,000 Free Monthly Tile Requests" (Q3 2025). Mapbox has been tracked since 2023-11-14.
