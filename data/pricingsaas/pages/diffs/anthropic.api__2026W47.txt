What happened
Between the Nov 9, 2026 and Nov 16, 2026 captures of Anthropic's pricing page, Pulse recorded one change: New Fable 5.2 model replaces Fable 5.1 as the flagship API model, priced 20% lower: input $8, output $40, cache read $0.20, cache write $10 per MTok (vs. Fable 5.1 at $10/$50/$0.25/$12.50). Fable 5.1 stays available under Legacy models at unchanged rates; fast mode (2x standard pricing) now also covers Fable 5.2. Pulse files it as a packaging change (new plan). The current page lists Opus 5.5 at $0.20 per MTok cache read + $4 per MTok input, Sonnet 5.5 at $2 per MTok input + $10 per MTok output, Opus 4.5 at $0.50 per MTok cache read + $6.25 per MTok cache write, Haiku 5.5 at $0.50 per MTok output + $0.13 per MTok cache write and Sonnet 4.5 at $0.30 per MTok cache read + $3.75 per MTok cache write.
It lands 38 days after Anthropic's previous change, "Anthropic API launches Haiku 5.5 at $0.10/$0.50, halves Sonnet 5.5 cache reads" (Oct 8, 2026). Before that Pulse recorded "Anthropic API: Opus 5.5 launches, replaces Opus 5 as flagship" (Sep 27, 2026). Anthropic has been tracked since 2024-11-17.
In the same window Microsoft, OpenAI, X, Google and Mistral AI also changed their AI & Machine Learning pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
