What happened
Between the Aug 17, 2026 and Aug 24, 2026 captures of X's pricing page, Pulse recorded 2 changes: Main pricing table narrowed to only grok-4.6 (grok-4.5 no longer shown, only referenced in a collapsed FAQ); two new Imagine models grok-imagine-image-2.0 (from $0.04/img) and grok-imagine-video-1.5 (from $0.08/sec) were added; 'Build on your own' plan's 4th benefit bullet changed from a generic documentation callout to a specific free Playground callout for testing Grok models before paying. Pulse files it as a packaging change (package change, feature change) with a neutral direction. Pulse's latest capture (Oct 12, 2026) lists grok-4.3 at $1.25 per 1M input tokens + $2.5 per 1M output tokens, grok-build-0.1 at $1 per 1M input tokens + $2 per 1M output tokens, grok-imagine-image-quality at $0.01 per input image + $0.05 per output image (1K resolution), grok-imagine-image at $0 per input image + $0.02 per output image (1K resolution) and grok-imagine-video at $0.01 per input second of video + $0 per input image.
It lands 19 days after X's previous change, "x.ai: Speech-to-Speech Voice API pricing changed from flat rate to starting-at" (Aug 5, 2026). Before that Pulse recorded "X swaps flagship model — grok-4.5 costs more, sees less, drops coding model" (Jul 13, 2026), "xAI: Grok lineup replaced (grok-4.3, grok-build-0.1), smaller context windows" (Jul 4, 2026) and "X launches Grok coding model and image/video/voice API pricing" (May 29, 2026). X has been tracked since 2025-10-11.
