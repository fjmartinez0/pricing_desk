What happened
Between the Oct 26, 2026 and Nov 2, 2026 captures of Baseten's pricing page, Pulse recorded 2 changes: elephant-1 input price now shown at $0.035/1M tokens (was hidden); mammoth-1 input price now shown at $0.10/1M tokens (was hidden). New model joey-1 added to Model APIs at $0.01/1M input tokens. In detail: elephant-1 and mammoth-1 Model API input pricing is now publicly shown ($0.035 and $0.10 per 1M tokens respectively); both previously showed no price; New model 'joey-1' added to the Model APIs catalog at $0.01 per 1M input tokens. Pulse files it as a pricing change (price revealed, feature added) with an upward direction. The current page lists Pro at $1, Enterprise at $1 and Basic at $1.32 DeepSeek V4 Pro 0813 input (per 1M tokens) + $0.30 Kimi K3 cache input (per 1M tokens).
It lands 3 days after Baseten's previous change, "Baseten adds Base Labs joey-1 model to Model API rate table at $0.01 input" (Oct 30, 2026). Before that Pulse recorded "Baseten: Input pricing revealed for elephant-1 ($0.035) & mammoth-1 ($0.10)" (Oct 29, 2026), "Baseten: Model APIs: Reflection Beam token prices cut: input $1.30 to $0.40, cache input $0.13 to $0.04, output $4.30…" (Oct 26, 2026) and "Baseten adds elephant-1 and mammoth-1 models from Base Labs, pricing TBD" (Oct 22, 2026). Baseten has been tracked since 2026-02-26.
