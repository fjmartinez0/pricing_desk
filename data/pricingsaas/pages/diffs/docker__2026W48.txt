Docker pricing FAQ
How much does Docker cost?
Docker pricing starts at $9/user/mo on Docker Pro, billed annually. Docker lists 4 plans on its pricing page; the Docker Personal plan is free.
Does Docker have a free plan?
Yes. Docker's Docker Personal plan is free; paid plans start at $9/user/mo on Docker Pro, billed annually.
What pricing model does Docker use?
Docker uses subscription + usage pricing across 4 plans, with a free tier.
When did Docker last change its pricing?
Nov 20, 2026: Docker launches Cloud Sandboxes at $0.07/hr, trims Desktop cards to Free/Teams.
How often has Docker changed its pricing?
Pulse has recorded 13 pricing changes for Docker since it started tracking on Nov 14, 2023; the pricing page was last checked on Nov 23, 2026.
What does “tracked since” mean?
It's the date of the first saved copy of the pricing page that Pulse checked for changes against a later copy. For a few companies we hold older copies that Pulse never checked for changes, and those don't change this date. If Pulse has never checked two copies, it's the date of the first saved copy.

Pulse compares Docker with Hypervault, Aws and Google Cloud.
