What happened
Between the Sep 21, 2026 and Sep 28, 2026 captures of Respondent's pricing page, Pulse recorded one change: Prepaid Credit Bundle model (buy 2,160 credits upfront, 15% off, tiers $2k/$50k/$500k+) replaced with Annual Commitment model (commit annual volume from $7.5K/year for stepped per-session rates, tiers $7.5K/$20K/$50K/$500K+); FAQ rewritten (Credit Bundle question -> annual commitments question) and new 'How is API pricing different?' FAQ added. In detail: Replaced prepaid 'Credit Bundle' pricing (buy 2,160 credits up-front for 15% off vs pay-as-you-go, tiers $2k/$50k/$500k+) with an 'Annual Commitment' model: commit an annual recruiting volume from $7.5K/year to step down per-session rates, new tiers $7.5K/$20K/$50K/$500K+. Default calculator view now shows the PAYG/list rate (B2C $40, B2B $80/session) instead of a discounted committed rate. FAQ replaced 'How does the Credit Bundle work?' with 'How do annual commitments work?' and added a new 'How is API pricing different?' question. Pulse files it as a packaging change (package change) with a neutral direction. The current page lists Pay as you go at $80 per B2B moderated session + $40 per B2B unmoderated session, $7.5K / year at $22.5 per consumer unmoderated session + $18 per consumer API session, $20K / year at $34 per consumer moderated session + $32 per B2B API session, $50K / year at $20 per consumer unmoderated session + $14 per consumer API session and $500K+ / year at $56 per B2B moderated session + $24 per B2B API session.
It lands 48 days after Respondent's previous change, "Respondent: Committed-bundle tier restructured ($100k→$500k+, 40%→30% off)" (Aug 10, 2026). Before that Pulse recorded "Respondent: pricing restructured to annual-commitment model (save 40%)" (Jul 27, 2026). Respondent has been tracked since 2026-05-04.
