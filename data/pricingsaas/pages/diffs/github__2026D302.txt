What happened
Between the Oct 28, 2026 and Oct 29, 2026 captures of GitHub's pricing page, Pulse recorded 2 changes: Enterprise now includes GitHub Copilot access and Agent governance as bundled features; tagline changed from 'Security, compliance, flexible deployment' to 'AI-powered, governed at enterprise scale'; Additional add-ons section expanded with three new cards: GitHub Code Quality, GitHub Code Security, and GitHub Secret Protection, each linking to its own pricing/learn-more page. Pulse files it as a packaging change (feature added, new add-on) with an upward direction. The current page lists Team at $4, Enterprise at $21, GitHub Codespaces at $0.18 per core hour compute + $0.07 per GB storage and Git Large File Storage at $5.
It lands 10 days after GitHub's previous change, "GitHub renames Copilot secret scanning, adds AI push protection detection" (Oct 19, 2026). Before that Pulse recorded "GitHub adds usage-based AI detection for push protection to Secret Protection" (Oct 17, 2026). GitHub has been tracked since 2023-11-14.
In the same window GitLab also changed their Software Development & Testing pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
