What happened
Between the Nov 4, 2026 and Nov 5, 2026 captures of Baseten's pricing page, Pulse recorded one change: Three new models added to Model APIs token pricing: joey-1 ($0.01/1M input), DeepSeek V4.1 Flash 1017 Fast ($0.60 in / $0.014 cache / $2.40 out), and Kimi K3.1 Pro ($2.00 in / $0.20 cache / $10.00 out per 1M tokens). Pulse files it as a product change (feature added) with an upward direction. The current page lists Pro at $1, Enterprise at $1 and Basic at $1.32 DeepSeek V4 Pro 0813 input (per 1M tokens) + $0.30 Kimi K3 cache input (per 1M tokens).
It lands 2 days after Baseten's previous change, "Baseten scraps Basic/Pro/Enterprise tiers, adds Sandboxes usage pricing" (Nov 3, 2026). Before that Pulse recorded "Baseten adds Base Labs joey-1 model to Model API rate table at $0.01 input" (Oct 30, 2026), "Baseten: Input pricing revealed for elephant-1 ($0.035) & mammoth-1 ($0.10)" (Oct 29, 2026) and "Baseten: Model APIs: Reflection Beam token prices cut: input $1.30 to $0.40, cache input $0.13 to $0.04, output $4.30…" (Oct 26, 2026).
