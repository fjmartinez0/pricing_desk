What happened
Between the Oct 26, 2026 and Nov 2, 2026 captures of Lilt's pricing page, Pulse recorded 2 changes: New Team plan added as entry tier ahead of Business: unlimited users/collaboration, 3 included domains; Business now builds on Team features. All plans Contact Sales; Business/Enterprise feature lists rewritten: Business connectors, contextual models, agents/copilots replaced by 5 domains, FDE support, CSM, onboarding; Enterprise adds unlimited domains, BYO LLM, SSO, COT audit trails. Pulse files it as a packaging change (feature change, new plan) with an upward direction. The current page lists MCP - Analytics at $0.01 per API call, MCP - Enterprise Governance at $0.01 per API call, MCP - Connectivity at $0.01 per API call, MCP - Context Management at $0.01 per API call and MCP - Multimodal Processing at $0.01 per API call.
It lands 122 days after Lilt's previous change, "Lilt: MCP (Model Context Protocol) support added to all plans" (Jul 3, 2026). Before that Pulse recorded "Lilt launches MCP pricing for all plans with full LLM integration" (Jun 22, 2026). Lilt has been tracked since 2026-04-22.
