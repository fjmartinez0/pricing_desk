What happened
Between the Nov 16, 2026 and Nov 23, 2026 captures of CodeRabbit's pricing page, Pulse recorded one change: Added Triage Rules (Team+), Security Merge Blocking (Advanced/Enterprise) and API/MCP server access on all plans; CodeRabbit AI Engineer renamed CodeRabbit Agent. Pulse files it as a product change (feature added). The current page lists Essentials at $24, Team at $48, Advanced at $72, Usage-based reviews at $0.25 per reviewed file and CodeRabbit Agent at $0.40 per agent minute.
This weekly roll-up includes 2 changes Pulse first recorded in a shorter period: "CodeRabbit strips Agent access from Essentials, adds Triage Rules for Team+" (Day 325, 2026, saved Nov 21, 2026) and "CodeRabbit includes API and MCP server access on every plan now" (Day 322, 2026, saved Nov 18, 2026). They are the same changes, not new ones. Before that, CodeRabbit's previous recorded change was "CodeRabbit renames Agent to CodeRabbit Engineer, drops $0.40/min from card" (Oct 10, 2026). CodeRabbit has been tracked since 2026-05-14.
In the same window GitLab, Windsurf, Replit, GitHub and JetBrains also changed their Software Development & Testing pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
