What happened
Between the Oct 26, 2026 and Nov 2, 2026 captures of GitHub's pricing page, Pulse recorded 2 changes: Additional add-ons grid adds GitHub Code Quality, Code Security and Secret Protection as standalone add-ons; sandbox drops 'public preview' label; Enterprise plan feature list now leads with GitHub Copilot access and Agent governance. Pulse files it as a packaging change (feature added, new add-on) with an upward direction. The current page lists Team at $4, Enterprise at $21, GitHub Codespaces at $0.18 per core hour compute + $0.07 per GB storage and Git Large File Storage at $5.
It lands 4 days after GitHub's previous change, "GitHub supercharges Enterprise with bundled Copilot, Agent governance, and…" (Oct 29, 2026). Before that Pulse recorded "GitHub renames Copilot secret scanning, adds AI push protection detection" (Oct 19, 2026) and "GitHub adds usage-based AI detection for push protection to Secret Protection" (Oct 17, 2026).
