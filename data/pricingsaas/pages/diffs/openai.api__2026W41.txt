What happened
Between the Sep 28, 2026 and Oct 5, 2026 captures of OpenAI's pricing page, Pulse recorded 2 changes: API model card updated from GPT-6 Sol to GPT-6.1 Sol, tagline now 'Built to power complex coding and agentic workflows at scale'; API Sol model cached input price cut from $0.20 to $0.10 per 1M tokens (GPT-6 Sol → GPT-6.1 Sol); input $2.00 and output $10.00 unchanged. Pulse files it as a pricing change (feature change, price decrease) with a downward direction. The current page lists gpt-image-2.5-flare at $2 per 1M cached image input tokens + $30 per 1M image output tokens, gpt-6.1-sol at $0.2 per 1M cached input tokens (long context) + $2 per 1M input tokens (short context), gpt-6-luna at $0.25 per 1M cache write tokens (long context) + $0.2 per 1M input tokens (long context), gpt-5.6-sol at $30 per 1M output tokens (long context) + $8 per 1M input tokens (long context) and gpt-6-astra at $20 per 1M input tokens (long context) + $1 per 1M cached input tokens (short context).
It lands 34 days after OpenAI's previous change, "Openai API Business: new $100/mo Premium seat tier + 200-employee cap" (Aug 31, 2026). OpenAI has been tracked since 2023-11-14.
In the same window Microsoft, Anthropic, Google, X and Metabase also changed their AI & Machine Learning pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
