Supermetrics renames Management API access to Platform API access
Verified Oct 12, 2026·Data & Analytics·Direction: neutral

1 change·2 captures·Oct 5, 2026 → Oct 12, 2026
What happened
Between the Oct 5, 2026 and Oct 12, 2026 captures of Supermetrics's pricing page, Pulse recorded one change: Management API access renamed Platform API access; comparison row 'Data API & MCP access' shortened to 'Data API access'. Pulse files it as a product change (positioning) with a neutral direction. The current page lists Starter at $44 and Growth at $177.
It lands 14 days after Supermetrics's previous change, "Supermetrics drops Data API & MCP access from Starter and Growth" (Sep 28, 2026). Before that Pulse recorded "Supermetrics strips automated refresh, dashboards from Starter, Growth, Enter" (Sep 14, 2026). Supermetrics has been tracked since 2024-10-01.
In the same window Google, DAT Freight & Analytics, Amplitude, Mixpanel and Tableau also changed their Data & Analytics pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
