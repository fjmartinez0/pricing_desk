What happened
Between the Nov 13, 2026 and Nov 14, 2026 captures of DeepSeek's pricing page, Pulse recorded one change: Two new priced API add-ons introduced: File Parsing/OCR API at $0.225 per 1,000 pages, and Speech APIs (Text-to-Speech $0.45/10K characters, Speech-to-Text/ASR $0.116/hour of audio), both at a limited-time 50% off launch price ($0.225 and $0.058 respectively). Pulse files it as a packaging change (new add-on). The current page lists DeepSeek Flash at $0.15 per 1M input tokens (cache miss) + $0.30 per 100M input tokens (cache hit) and DeepSeek V4 Pro at $0.66 per 1M input tokens (cache miss) + $2.20 per 100M input tokens (cache hit).
It lands 9 days after DeepSeek's previous change, "DeepSeek ends free Search/Fetch calls via Claude Code, now $0.75/1K requests" (Nov 5, 2026). Before that Pulse recorded "DeepSeek launches Search and Fetch APIs at $0.75 per 1K requests from Nov 1" (Oct 18, 2026), "DeepSeek launches Search and Fetch APIs at $0.75 per 1,000 requests" (Oct 17, 2026) and "DeepSeek extends 50% off-peak API discount to Chinese public holidays all day" (Sep 20, 2026). DeepSeek has been tracked since 2026-05-16.
In the same window OpenAI, Anthropic, X, Metabase and Google also changed their AI & Machine Learning pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
