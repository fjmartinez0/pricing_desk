What happened
Between the Nov 16, 2026 and Nov 23, 2026 captures of Addigy's pricing page, Pulse recorded one change: New Compare All Features by Plan table discloses SCIM, Platform SSO, Okta Workflows, Public API v2/webhooks, LAPS/FileVault/Activation Lock, and Splashtop remote access — none previously shown on the pricing page. In detail: New 'Compare All Features by Plan' table discloses previously unlisted capabilities: device security (Activation Lock, FileVault, LAPS, USB blocking), identity/admin controls (SCIM, Platform SSO, Okta/Entra IdP, SAML, MFA, IP allowlist), API/integrations (Public API v2, webhooks, Okta Workflows, PSA/IT Glue ticketing), and remote tools (Live Terminal, LiveDesktop, Splashtop). Pulse files it as a product change (feature added).
It lands 63 days after Addigy's previous change, "Addigy: launches AI-powered Intelligence Suite tier, drops standalone iOS Management plan" (Sep 20, 2026). Addigy has been tracked since 2026-02-25.
In the same window Microsoft also changed their Cybersecurity & Identity Management pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
