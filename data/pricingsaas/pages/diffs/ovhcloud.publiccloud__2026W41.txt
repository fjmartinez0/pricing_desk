What happened
Between the Sep 28, 2026 and Oct 5, 2026 captures of OVHcloud's pricing page, Pulse recorded one change: Instance tables (b3/c3/r3) no longer list fixed local NVMe sizes (e.g. 50-400 GB); column now reads 'Local storage low latency **', consistent with local storage being billed separately from Oct 1, 2026. Pulse files it as a product change (feature change) with a neutral direction. The current page lists Public IP at $2.33 per IP address per month, Virtual Machine Instances at $7.08 per instance per month, Cloud GPU at $630 per instance per month, Block Storage at $48.18 per TB per month and File Storage at $170.82 per TB per month.
It lands 21 days after OVHcloud's previous change, "OVHcloud Publiccloud: AI GPU resource unit quota doubled (4→8)" (Sep 14, 2026). Before that Pulse recorded "OVHcloud Publiccloud: MongoDB Discovery database service to be discontinued 31/08/2026" (Aug 4, 2026). OVHcloud has been tracked since 2026-05-15.
In the same window Vultr, Digitalocean, Google Cloud and Scale also changed their Cloud & DevOps pricing pages. Those moves are listed further down, and the Pulse Agent can compare them side by side.
