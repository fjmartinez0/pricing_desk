Coderabbit stripped Change Stack Chat and Agent access from Essentials
By Rob Litterst, Co-founder, PricingSaaS
Published Nov 21, 2026
Coderabbit removed Change Stack Chat and Agent access from its Essentials plan.

What changed
Coderabbit removed Change Stack Chat and Agent access from its Essentials plan. Team and higher tiers gained Triage Rules, which merges ready pull requests, closes stale ones, and sends Slack reminders automatically; Advanced and higher tiers gained Security Merge Blocking. The company also renamed AI Engineer to Agent and Autofix to Fix Comments.
Why it matters
For a team relying on Essentials, chat-based agent access and Change Stack Chat now require upgrading to Team or higher — a cost worth checking before renewing. Pulse tracked 17 real pricing changes to Coderabbit's page in the last 365 days, with an average 11-day gap between them, and this move landed just 3 days after Coderabbit opened API and MCP server access to every plan on Nov 18, 2026. That pace means tier boundaries here move often: a team building a workflow around Coderabbit's Essentials plan should re-check which features it depends on before committing. Watch whether Coderabbit keeps pulling agent and chat capabilities up into paid tiers, which would turn Essentials into more of a trial than a production plan.
In context
Coderabbit has repackaged its plans at an unusually fast clip: Pulse tracked 17 changes to its pricing page in the last 365 days, with an average 11-day gap between them, and this change lands just 3 days after Coderabbit opened API and MCP server access to every plan on Nov 18, 2026. Feature additions are common across the market too — Pulse tracked 829 pricing changes involving a feature addition in the last 180 days, 24.2% of the 3,421 changes it saw, with Together, MindsDB and Baseten among the most frequent, and Baseten, Lumaai and Raycast all shipping additions of their own this same week. The sharper read: Coderabbit isn't just adding features, it's redrawing which tier gets them — pulling Agent chat access down from Essentials even as it hands Team and Advanced new automation and security controls, a sign it is using its fast cadence to push serious users toward paid tiers rather than just layering on capability.
Common questions
What should a team on Essentials do now?
If a workflow depends on chatting with the CodeRabbit agent, moving to Team restores that access along with the new Triage Rules automation — weigh that against staying on Essentials before renewing.
Should we expect more Coderabbit tier changes soon?
Likely — Pulse's tracking shows Coderabbit moving its pricing page roughly every 11 days on average, so treat today's tier boundaries as temporary and recheck them before signing a longer contract.
What was renamed in this update?
AI Engineer became Agent and Autofix became Fix Comments — cosmetic renames that don't change what each tier includes.
