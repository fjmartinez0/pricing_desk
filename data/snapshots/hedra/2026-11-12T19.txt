Billing FAQ
How are production inference, model training and GPU Sandboxes priced?
GPU compute is priced per GPU-second. Your quote confirms the supported hardware, rates, included resources and billing terms. Model training and GPU Sandboxes are research previews.
Is dedicated inference the same as reserved GPU capacity?
Dedicated inference describes how your model is served. A reservation is a commercial commitment for agreed GPU capacity and a term. Confirm the supported workload, allocation, start date and billing terms with our team.
How is a Model Factory engagement priced?
Model Factory combines a scoped research engagement with compute for experiments and production serving. Your proposal identifies the research scope and compute charges. Bring us the problem you need to solve; you don’t need a finished model or complete dataset to start.
Can I buy compute without a research engagement?
Yes. You can discuss production inference or compute directly, or scope research and model development through Model Factory. Model training and GPU Sandboxes remain research previews.
Where can existing Model API customers find rates?
View Model API rates for current model-specific prices and configurations. Existing Model API calls use a prepaid USD wallet, separate from Play subscriptions. These catalog prices do not apply to custom-model compute or research engagements.
Do Play subscriptions and API usage share credits?
No. Play subscription credits and the API wallet are separate. The REST API and CLI use the API wallet. MCP uses the billing mode selected in your MCP settings.
Still have a billing question? Email support@hedra.com, or talk to our team about an engagement.
