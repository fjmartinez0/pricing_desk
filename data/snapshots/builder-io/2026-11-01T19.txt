Get answers to common questions
What's the difference between Code and Content?
Code enables product, design, and development teams to generate, iterate, and ship enterprise-ready web apps using your design system and codebase with full visual control.
Content allows marketing and content teams to generate, visually iterate, and optimize web and app experiences with the powerful combination of AI and the market-leading drag and drop visual editor.
Can I use both Code and Content together?
Yes and many teams do!
Components created in Code can be used by your whole team as part of your design system in Content.
Content created in Content can be pulled into apps and UIs built in Code.
Code is meant to accelerate and democratize code development. You don't want content living in code, so use Content instead.
So, subscriptions are per space, but what is a space?
Spaces keep your code, content, and projects organized. There are two types of spaces: Code spaces (for code generation projects) and Content spaces (for the content, models, and data powering your web and app experiences).
For Code, if you have completely separate teams working on entirely different projects and apps, it could make sense to create separate spaces.
What is an Agent credit?
An Agent credit is Builder's unified usage metric for generative AI operations across the Builder platform. Each Agent credit represents a fixed dollar value that covers the underlying model costs plus Builder's service margin.
What if I need more Agent credits?
On the Free plan, you get 15 Agent credits per day, with a total limit of 60 Agent credits per month.
Daily credits reset at midnight UTC and monthly credits reset on the first day of each calendar month. If you run out of credits, you will need to wait until those times, or upgrade to a Pro or Team plan.
On the Pro and Team plans for Code, you get 500 Agent credits per user per month, which resets every month on the same date that you started your subscription. If you need more, you can purchase in increments of 500 monthly AI credits for $25/month.
What if I need to add more users?
No problem! Our Pro and Team plans come with one seat included. If you need additional user seats, you can purchase them directly on the platform.
Should you need more than the allowed seats under these plans, you will need to upgrade your subscription plan.
Feel free to contact us for more details.
