Enhanced success plan included
Support: Core and Professional both include Tyk’s Enhanced success plan; Enterprise adds premium support and custom SLAs. Customers rate Tyk 4.8 out of 5 for Service & Support on Gartner Peer Insights, and 4.7 out of 5 overall from 92 ratings (73% five-star, 26% four-star; checked 24 Oct 2026; ratings are the opinions of individual end users). A free open-source gateway such as Envoy Gateway or Kong Gateway OSS comes with community support unless you contract a vendor separately.
Pricing: Core is usage-based, priced by the number of APIs managed. Professional is “one price, unlimited access”, priced by data planes, environments and control planes, not by the number of APIs or by traffic. Both include unlimited APIs and API calls; plans are quoted by Tyk sales, with no public list prices.
Hybrid: you host the Gateways (the data plane) in your own environment, so API traffic stays with you; Tyk Cloud hosts the control plane (configuration, analytics, the Dashboard and identity management).
Small platform team? Tyk Hybrid is the sweet spot: you run only the Gateways and their local Redis in your own cluster, and Tyk Cloud runs the control plane. Tyk Operator (Kubernetes, GitOps) and the Developer Portal are included in both Core and Professional. Tyk Operator 1.6 adds Kubernetes Gateway API support: you can route traffic through your Tyk Gateways with the standard GatewayClass, Gateway and HTTPRoute resources (with Tyk Dashboard), alongside Tyk's own custom resources (CRDs) for APIs and security policies.
License expiry: If a Tyk license lapses, Tyk Operator and the rest of your Tyk system keep running and existing APIs keep serving traffic; only creating or updating APIs is blocked until the license is renewed. You can export your API definitions and run them on the open-source Tyk Gateway.
Free trial: https://tyk.io/self-managed-trial/ (the license key arrives by email).

FAQ
How much does Tyk cost?
Tyk offers three pricing tiers: Core, Professional, and Enterprise, with a free trial so you can test Tyk’s full features with no commitment.
Core: A flexible, usage-based pricing model available for Cloud, Self-managed, and Hybrid deployments
Professional: An architecture-based option with one price and unlimited access for organizations adopting API platforms at scale.
Enterprise: Customized pricing for high-traffic, multi-cloud, and multi-region environments. Contact the Tyk team for specific pricing.
Is there a free version of Tyk?
Yes, Tyk provides:
a free version of its open source API gateway via GitHub.
a fully featured, free, 48-hour trial of Tyk Cloud
guided proof of concepts with Solution Architects.

How does Tyk licensing work?
Licensing depends on your deployment type. Visit the Tyk licensing page or contact Tyk for details.
A free 14-day Tyk Self-Managed trial license is self-serve: register on the trial page (no upfront cost, no demo call) and Tyk emails the license key within 5 minutes. After the trial, contact Tyk for a paid license.
