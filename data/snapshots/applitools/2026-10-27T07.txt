Applitools FAQs
What is the difference between Page testing and Component testing?
Page Testing: Validates full application screens and multi-step user flows in real browser environments, ensuring that full page layouts, dynamic content, and end-to-end user interactions render correctly.
Component Testing: Isolates individual UI elements (such as buttons, modals, or navigation bars) early in the development lifecycle—directly inside design systems or component libraries like Storybook—before they are assembled into full application pages.
How do Applitools Eyes and Autonomous work together?
Applitools Eyes: Provides Visual AI algorithms that analyze application screens to catch UI regressions across browsers, viewports, and operating systems.
Applitools Autonomous: Leverages AI to automatically author, execute, and maintain end-to-end functional test flows using plain English prompts without requiring manual test code.
Combined Power: On the Professional tier, both Eyes and Autonomous run seamlessly across both full Pages and isolated Components, delivering comprehensive visual and functional coverage across your entire software delivery pipeline.
What is Concurrent Test Execution?
Concurrency determines how many test executions or visual checks your team can execute simultaneously in parallel. Higher concurrency allows large development teams to run massive test suites in CI/CD pipelines in parallel, keeping build times fast and feedback loops immediate.
What is included with Private Cloud and Dedicated Deployments?
Private Cloud provides an isolated, single-tenant cloud environment dedicated exclusively to your organization. It includes Single Sign-On (SSO/SAML) integration, customizable data retention policies, and enterprise-grade security controls necessary for regulated industries.
What is Visual AI, and how does it differ from pixel matching?
Traditional pixel-matching tools compare images pixel-by-pixel, causing frequent false positives from minor rendering differences, dynamic dates, or screen resolution shifts. Applitools Visual AI emulates the human eye and brain, automatically ignoring harmless environment noise while highlighting actionable visual, structural, and content bugs.
What is the Ultrafast Grid (UFG)?
The Ultrafast Grid is a cloud execution engine that captures application DOM states during a single test run and instantly re-renders them across dozens of browser, viewport, and mobile device combinations simultaneously. This eliminates the latency and flakiness of running traditional grid infrastructure.
